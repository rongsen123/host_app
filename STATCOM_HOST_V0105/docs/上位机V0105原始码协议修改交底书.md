# 上位机V0x0105原始码协议修改交底书

## 1. 修改边界

本文件交给负责上位机的AI执行。当前开发任务没有修改
`docs/statcom_host`中的任何源码。

配套固件：

- DSP：`F:\DSP\SST_PRJ\4_STATCOM_CURRENT_LOOP`
- CPLD：`F:\Quartus_project\SST_prj\CPLD_EPM1270_STATCOM_MODBUS`
- 协议版本：`0x0105`

功率输出仍被DSP和CPLD硬封锁。不得因为本次协议修改增加解除PWM封锁、
强制继电器或绕过故障的功能。

## 2. 设计原则

DSP和CPLD只采集、上传、保存和比较ADC原始码，不在实时保护路径中换算V/A。
上位机负责：

1. 将上传的原始码换算为工程量，仅用于显示、趋势和记录；
2. 将用户输入的工程量保护值换算为原始码，再写入设备；
3. 写入后读取设备实际原始码，并重新换算显示；
4. 同时显示工程量和括号内原始码，便于现场核对。

## 3. 周期FC04寄存器变化

周期读取仍为从`0x0000`开始的29个寄存器，通信长度不增加。

| 地址 | V0x0105含义 | 上位机处理 |
|---|---|---|
| `0000` | 协议版本`0x0105` | 低于该版本不得使用原始码阈值界面 |
| `0005` | ADCINA0电网正半波绝对原始码 | `Vgrid = raw × Kgrid` |
| `0006` | ADCINA2交流电流绝对原始码 | 与`0007`相减后换算电流 |
| `0007` | ADCINA2零电流校准原始码 | `Iac = (raw-zero) × Kiac` |
| `0008` | CPLD Vdc最新原始码 | 仅作瞬时诊断 |
| `0009` | CPLD Vdc 256点平均原始码 | 建议用于Vdc工程量显示 |
| `000A` | 温度脉冲计数/100 ms | 保持原始计数；无标定曲线时不得伪显示摄氏度 |

`0010`的PLL频率`0.01 Hz/LSB`是算法输出，不是ADC工程量换算，本次保持不变。

建议的暂定换算系数如下，但必须允许以后用实物标定值替换：

```text
Kgrid = 0.2741878 V/count
Kiac  = 0.09887695 A/count
Kvdc  = 0.28568177 V/count
```

Vdc如存在零点标定，继续使用：

```text
Vdc = max(0, (vdc_average_raw - vdc_zero_raw) × Kvdc)
```

## 4. 保护阈值寄存器

三个阈值仍只在用户打开保护参数区、点击读取或执行写入时访问，不得加入
20 ms周期FC04轮询。

| 地址 | 设备接收/读回含义 | 固件默认及最大值 |
|---|---|---|
| `1000` | CPLD Vdc过压绝对ADC原始码 | `3410` |
| `1001` | DSP电网正半波过压绝对ADC原始码 | `1313` |
| `1002` | DSP交流电流过流偏差计数`abs(raw-zero)` | `51` |

用户仍输入V/A，上位机内部执行：

```text
vdc_trip_raw  = round((Vdc_trip / Kvdc) + vdc_zero_raw)
grid_trip_raw = round(Vgrid_peak_trip / Kgrid)
iac_trip_raw  = round(Iac_trip / Kiac)
```

写入前必须同时检查：

- DSP请求状态为STOP；
- 原始码不为0；
- `vdc_trip_raw <= 3410`；
- `grid_trip_raw <= 1313`；
- `iac_trip_raw <= 51`；
- 用户工程量与换算后的原始码同时展示并二次确认。

固件还会再次执行相同的原始码上限检查。FC06成功回显后，应立即用FC03
读回`1000-1002`，以设备实际原始码刷新界面，不能只保留用户输入值。

## 5. CPLD温度保护说明

温度阈值不开放Modbus配置。CPLD在本地每100 ms比较脉冲计数：

- 当前固定阈值：`5000 count/100 ms`；
- 当前方向假设：频率越高表示温度越高；
- 过温故障：CPLD故障bit8；
- 100 ms零脉冲传感器故障：CPLD故障bit11。

该阈值和方向尚未完成传感器实物标定。上位机只展示计数与故障状态，不提供
温度阈值写入控件，也不能把当前计数强行换算成摄氏度。

## 6. 必须修改的上位机位置

由负责上位机的AI根据当前源码结构定位并修改：

- 协议版本最低值和V0x0105兼容判断；
- `0007`解析：从有符号`0.01 A/LSB`改为无符号零点原始码；
- 实时总览、趋势和CSV中的Vgrid/Iac/Vdc换算；
- `1000-1002`的工程量输入、原始码换算、范围检查、写入和读回显示；
- 寄存器全表中的名称、单位和说明；
- 协议单元测试和真实帧测试。

不得更改周期读取的29寄存器长度，不得增加温度阈值写入，不得修改功率输出
安全逻辑。

## 7. 验收项目

1. 连接V0x0105固件，周期FC04仍稳定读取29个寄存器。
2. 零电流时确认`0006`接近`0007`，显示电流接近0 A。
3. 输入5.00 A时，暂定系数应换算为约`51`计数；写入并读回应一致。
4. 输入360.0 V电网峰值时，暂定系数应换算为约`1313`计数。
5. Vdc阈值写入CPLD后，DSP读回值、CPLD实际保持值一致。
6. 超过固件原始码上限的输入必须在上位机侧拒绝；绕过界面直接写入时设备
   必须返回Modbus异常`03`。
7. 温度区域只显示原始计数和bit8/bit11故障，不出现未标定摄氏度。
8. START/STOP、清故障、复位CPLD/DSP、ADC重新校零和通信诊断全部回归通过。
